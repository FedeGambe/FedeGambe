# Ciao, sono Federico Gamberini 👋

Vengo dall'economia e lavoro con i dati a Bologna. Unisco le due cose raccogliendo dati dal web, costruendo modelli predittivi e trasformandoli in strumenti che si possono usare davvero.

## 🔭 Cosa faccio

- **Previsioni e machine learning**: modelli LSTM, LightGBM e Random Forest per prevedere il prezzo di Bitcoin e il Fear & Greed Index ([Bitcoin_Prediction](https://github.com/FedeGambe/Bitcoin_Prediction), progetto per l'academy Data Science e Generative AI di Crif)
- **Monitoraggio dei prezzi**: scraping e analisi per capire quando conviene comprare, che si tratti di auto usate o di iPhone ([Vehicle_Price_Monitor](https://github.com/FedeGambe/Vehicle_Price_Monitor), [When_to_buy_iPhone](https://github.com/FedeGambe/When_to_buy_iPhone))
- **Finanza personale**: simulatori di busta paga netta e conti deposito, strategie con ETF obbligazionari a scadenza, una dashboard che legge e scrive i dati su Google Sheets ([simulatori](https://github.com/FedeGambe/simulatori), [Target_Maturity_ETF_Planner](https://github.com/FedeGambe/Target_Maturity_ETF_Planner), [Wally](https://github.com/FedeGambe/Wally))
- **Strumenti**: skill per Claude Code che trasformano un repository in vetrina ([skill-vetrina](https://github.com/FedeGambe/skill-vetrina))
